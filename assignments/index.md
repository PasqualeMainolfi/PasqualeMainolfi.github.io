# Assignments

Exam projects for each course. Pick one project from the list for your course and year.

- [Sound Synthesis & Processing](sound-processing/index.md)
- [Multimedia Programming](multimedia-programming/index.md)

## How it works

Each assignment card lists:

| Field | Meaning |
|:------|:--------|
| **Difficulty** | How demanding the project is. |
| **Max participants** | How many students can work on it together. |
| **Max score** | Highest grade (out of 30) you can get with the base project. |
| **Bonus** | Extra points you can earn with the optional features in *Bonus score*. |
| **Presentation** | What you must deliver along with the code (documentation, slides…). |

{: .important }
Documentation is mandatory for every project. During the exam you present your work and answer questions about the design choices, the implementation and the results.
