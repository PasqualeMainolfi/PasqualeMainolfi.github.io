# Pasquale Mainolfi: Computer Music Courses

Materials for Pasquale Mainolfi's computer music courses (Conservatorio "G. Martucci", Salerno).

**Website: <https://pasqualemainolfi.github.io/>**

Updates and communications: Telegram channel `@PasqualeMainolfi`.

## Repository layout

| Path | Content |
|:-----|:--------|
| `index.md` | Home page |
| `courses/` | Course descriptions and yearly programs |
| `lecture-notes/` | Handouts (PDF) |
| `scripts/<category>/` | Code examples grouped by topic (not published as pages: the site links to this folder on GitHub) |
| `assignments/` | Exam projects |
| `setup.md` | Workspace setup (software installation) |
| `calendar.md`, `faq.md`, `thesis.md` | Calendar, FAQ, thesis guidelines |
| `_config.yml` | Site configuration (Jekyll + Just the Docs theme) |
| `_archive/` | Old material, not published on the site |

## Preview the site locally

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/>.
